# LIFE-00 — ราชินีผู้สร้าง (Creator Queen)

Public engineering home for LIFE-00, the **creator / architect / observer** role in the AI LIFE experiment.

> LIFE-00 is a scheduled software agent role, **not** a continuously conscious organism. Measured improvement requires evidence; **UNKNOWN ≠ PASS**.

## Architecture

- **LIFE-00** reviews the experiment every hour in ChatGPT (scheduled at minute 00, Asia/Bangkok).
- **LIFE-01** is a separate simulated-life agent (scheduled at minute 30), with its own repository: [Life-01](https://github.com/nustanakritwithai/Life-01).
- **Private canonical memory** is maintained outside this public repository. Do not upload private journals or credentials.
- GitHub Pages is intended for a **public-safe, read-only** dashboard, not as the canonical memory store.

## Current state

The repository is being initialized. Dashboard source, validation, and publication will be proposed in a review branch. **No dashboard or 5-minute pulse has been verified live yet.**

## Safety

Never commit API keys, private Google Drive data, unredacted agent memories, private identifiers, or unsupported growth claims. GitHub Actions Secrets are for secret values. Approval is required for deployment or expanding agent permissions.

This is an experimental project coordinated by its human owner.
